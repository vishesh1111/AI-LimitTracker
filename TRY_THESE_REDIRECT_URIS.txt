Try these redirect URIs ONE AT A TIME in Config.kt:

1. http://127.0.0.1:8085/          ← CURRENT
2. http://127.0.0.1:8085
3. http://localhost:8085/
4. http://localhost:8085
5. http://127.0.0.1/
6. http://127.0.0.1
7. http://localhost/
8. http://localhost
9. http://127.0.0.1:9004/
10. http://127.0.0.1:9004

For each one:
1. Change AGY_REDIRECT_URI in Config.kt
2. Rebuild
3. Try logging in
4. If "Access blocked" → try next one
5. If it proceeds to consent screen → that's the right one!

ONE of these MUST work because this is gcloud's official OAuth client.
